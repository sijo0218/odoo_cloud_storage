The Problem

  • Local filestore balloons to 100s of Gigabytes from CRM, PDFs, and invoices.
  • Nightly database backups become agonizingly slow or fail from disk exhaustion.
  • SSD cloud hosting prices escalate rapidly on AWS EBS or DigitalOcean volumes.
  • Heavy file downloads tie up Odoo Python HTTP workers, slowing down users.

The Solution

  • Seamlessly routes attachments directly to high-speed S3-compatible buckets.
  • Reclaims 100% of server disk space with automatic local filestore cleanup.
  • Uses Cloudflare R2 ($0 egress fees) or Wasabi/S3 at fractions of a cent per GB.
  • Direct pre-signed URLs allow users to download files directly from the CDN.
